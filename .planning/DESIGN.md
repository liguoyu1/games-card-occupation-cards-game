# 职业卡牌 (Occupation Cards) — 设计方案

## 1. 项目概述

**名称**：职业卡牌 (Occupation Cards)  
**类型**：回合制策略卡牌游戏（TCG/CCG）  
**对标**：炉石传说 (Hearthstone)  
**引擎**：Flutter + Flame  
**目标平台**：iOS（首发）、Android、Web、macOS

### 核心玩法
- 1v1 对战，双方各 30 点生命值
- 每回合自动获得递增法力水晶（1-10 回合满 10 费）
- 出牌消耗法力值，随从登场可攻击
- 消灭对方英雄获胜

## 2. 游戏机制设计

### 2.1 炉石核心机制（完整实现）

| 机制 | 关键词 | 效果 |
|------|--------|------|
| 冲锋 (Charge) | 登场即可攻击 | Rush |
| 嘲讽 (Taunt) | 必须先攻击嘲讽目标 | Taunt |
| 圣盾 (Divine Shield) | 首次伤害免疫 | DivineShield |
| 战吼 (Battlecry) | 登场时触发 | Battlecry |
| 亡语 (Deathrattle) | 死亡时触发 | Deathrattle |
| 风怒 (Windfury) | 一回合可攻击两次 | Windfury |
| 冻结 (Freeze) | 目标下回合无法攻击 | Freeze |
| 潜行 (Stealth) | 无法被指定为目标（攻击后失效） | Stealth |

### 2.2 英雄技能（2 费）

| 职业 | 技能名称 | 效果 |
|------|----------|------|
| 服务 | 临时工 | 召唤 1/1 随从 |
| 公职 | 盾牌 | 获得 3 点护甲 |
| 技艺 | 焊枪 | 对任意目标造成 2 点伤害 |
| 文教 | 备课 | 抽一张牌 |

### 2.3 法力值系统

- 回合开始：法力值 +1（上限 10）
- 法力值上限 = 当前回合数（最多 10）
- 出牌消耗法力，未使用不继承

## 5. UI/UX 设计 — 精品化视觉方案

### 5.1 设计哲学

定位为 **"精致的职业卡牌艺术品"**，非 Demo 非原生风格。三大原则：

1. **质感优先** — 每一个像素都有目的，拒绝"凑合能用"
2. **动效叙事** — 卡牌不是静止的，每一张牌都有生命
3. **反馈极致** — 用户每一个操作都有明确、愉悦的视觉/听觉回馈

### 5.2 全局视觉系统

#### 配色方案 — 深空商务风

```
主背景色    #0A0E27 (深海夜空蓝) — 战斗背景

强调色      #FFB800 (琥珀金) — 稀有元素、按钮主色

```
